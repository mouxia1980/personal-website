### 登录方法（Python）

后台有验证码，验证码与 PHPSESSID 绑定，**必须在同一个 session 中获取验证码并提交登录**。

```python
import requests, pickle

session = requests.Session()
session.headers.update({
    'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36',
})

# Step 1: 访问登录页，建立 session
session.get('http://www.dlhaida.com/index.php?m=sysadmin&c=login')

# Step 2: 获取验证码图片
captcha_resp = session.get('http://www.dlhaida.com/admin/verifycode.php')
with open('/tmp/captcha.png', 'wb') as f:
    f.write(captcha_resp.content)
# 查看 /tmp/captcha.png，人工识别验证码

# Step 3: 提交登录（验证码替换为实际识别的结果）
login_data = {
    'username': 'haida',
    'password': 'd5UxpJ4C',
    'verifycode': 'XXXX',  # 填入验证码
    'button': 'login'
}
resp = session.post(
    'http://www.dlhaida.com/index.php?m=sysadmin&c=login&f=check',
    data=login_data,
    allow_redirects=True
)

# Step 4: 保存 session 供后续操作使用
import pickle
with open('/tmp/login_session.pkl', 'wb') as f:
    pickle.dump(session, f)
```

### 登录后恢复 session
```python
import pickle
with open('/tmp/login_session.pkl', 'rb') as f:
    session = pickle.load(f)
```

### ⚠️ 验证码注意事项
1. 验证码与 session 绑定，每次获取验证码都会刷新
2. 验证码有时效性，拿到后要尽快提交
3. 如果登录失败提示"验证码不正确"，需要重新获取新的验证码
4. 验证码图片约 1500-1800 bytes，PNG 格式

## 重要警告

### ❌ Smarty 模板引擎冲突
- 该 CMS 使用 **Smarty** 作为模板引擎
- Smarty 使用 `{}` 作为模板标签符号
- **直接在模板中插入 JSON-LD（含 `{}`）会导致 Smarty 编译报错**
- 错误表现：前台显示 Fatal error / SmartyCompilerException
- 如果要添加 JSON-LD，需要使用 `{literal}{/literal}` 包裹，或使用其他绕过 Smarty 解析的方法

### 模板文件物理位置
- 服务器路径：`/webHome/host7326879/www/system/templates/default/`
- 模板变量：`{$skin}` = 皮肤路径，`{$seo}` = SEO 配置
- 模板标签：`{nav}`, `{loop}`, `{if}`, `{/if}` 等都是 Smarty 语法
